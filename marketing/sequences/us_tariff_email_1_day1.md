# US Post-Tariff Sequence — Email 1 (Day 1: The Tariff Hook)

**Sequence:** US cold email, 5 touches / 21 days (MASTER_ACQUISITION_PLAN.md, Section 2)
**Send day:** Day 1
**Goal:** Open with the buyer's own import profile (from customs data) + tariff-removal math. Get permission to quote.
**Single CTA:** "Worth a quote?" (reply)

---

## Subject (primary — see README for 6 A/B variants)

```
The 50% tariff is gone — [MATERIALS_THEY_IMPORT] math for [COMPANY]
```

```

[SENDER_NAME]

divyastones.com | WhatsApp: +91-94141-67278
```

## Operator notes

- **Personalization source:** every token comes from customs data (Volza / ImportGenius / Panjiva) — materials, port, current supplier country. Do NOT send this email with generic fills; if customs data is missing for a prospect, they don't get this sequence.
- **[MATERIALS_THEY_IMPORT]:** use their actual materials (e.g., "Steel Grey and Black Galaxy granite"). Pitch what they already buy — not only Verde Guatemala (Plan, key change #3).
- **Send from secondary domain mailbox only** (divyastonesexport.com / divyastone.co). NEVER from divyastones.com (Plan, key change #5). Website link in signature is fine.
- **No attachments on Day 1** — protects deliverability during list warm-up.
- If they reply "yes": quote out within 24–48h, hard limit (Plan, Section 8). Remove from sequence on any reply.
